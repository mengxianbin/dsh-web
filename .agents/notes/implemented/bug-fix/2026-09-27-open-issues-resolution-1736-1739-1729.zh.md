# Agent Note: 未结 Issue 综合解决（#1736, #1739, #1729）

Status: implemented

## 问题

经排查，仓库中存在三条合理且必要的未结 Issue：

1. **#1736**：在 `dsh-skill-explorer`（以及 `dsh-ssh`）中，面板头部的「‹ 返回会话」按钮（`data-dsh-center-view-back`）点击完全无反应。客户端入口在其 `inject` 声明中遗漏了 `layout` 服务，导致在 Cordis 严格访问规则下 `ctx.get('layout')` 恒返回 `undefined`。因此，`controller.close()` 调用 `layout.selectPanel(null)` 静默失效，中栏面板无法关闭回到会话视图，活跃面板状态同步亦未建立。
2. **#1739**：在 `dsh-usage` 中，`readNamespace` 调用了 `settings.get(ns)`，而 DSH 0.1.7 中 `settings` 服务升级为 `SettingsForms`，该方法已移除。调用抛出 TypeError 被 catch 静默吞掉并返回 `undefined`。导致 profile patch 中通过 `apiKeyEnv` 声明凭证的 `pi-ai` provider（如 `opencode-go`、`zai` 等）被判定为 `credential: "none"`，余额与个人套餐额度窗口（5h/周/月）无法探测并展示。
3. **#1729**：在 `dsh-task-board` 中，当 Host 端同源回环护栏拒绝请求返回 403 `{"ok":false,"error":"forbidden"}` 时，客户端将其实际翻译为 `board.hostError.unauthorized`（「登录状态已失效，请刷新页面后重试」）。该误导性文案将排查方向引向登录认证与会话过期，而非桌面外壳或反向代理剥离 Origin / Cookie 凭据的真实网络环境根因。

## 决策

1. **技能中心与 SSH 面板导航调用修复（#1736）**：
   - 在 `packages/dsh-skill-explorer/src/client/index.ts` 与 `packages/dsh-ssh/src/client/index.ts` 的 `export const inject` 中补充 `'layout'`。
   - 对 `ctx.get('layout')` 访问增加保护，确保 `controller.close()` 顺利调用 `layout.selectPanel(null)` 关闭面板并返回到当前活跃会话。
   - 补充单元测试锁定 inject 声明与布局交互行为。

2. **DSH 0.1.7 外部配置读取与 Volatile 解引用（#1739）**：
   - 强化 `packages/dsh-usage/src/host/usage-service.ts` 中的 `readNamespace`：
     1. 兼容 0.1.7 之前版本的 `settings.get(ns)`；
     2. 支持 DSH 0.1.7 `SettingsForms.describe({ redactSecrets: false })`，按 `d.ns === ns` 或特定 provider 结构精确匹配；
     3. 探测 `ctx.root.loader` 或 `ctx.loader` 中的活跃条目；
     4. 回退探测 `configEditor.configuration()` 中的配置行。
   - 增加 `unwrapVolatiles` 递归解引用 Cosmokit / Cordis `Volatile` 引用与 `ConfigRef` 的 `.get()` 值。
   - 增加 `routeBaseUrl`，将 Origin 校验（`balanceAppliesToRoute`）统一覆盖到 `pi-ai` 与自定义 `llm-deepseek` 路由。
   - 补充覆盖 `settings.describe()` 带 volatile 解引用、`configEditor` 回退及自定义 deepseek `baseURL` 余额排除的单元测试。

3. **任务看板护栏拒绝文案细分（#1729）**：
   - 在 `packages/dsh-task-board/src/client/host-api.ts` 的 `HostApiFailure` 中新增 `'forbidden'` 类型。
   - 将 403 `forbidden`（护栏拒绝）与 401 `unauthorized`（认证过期）清晰分流。
   - 在 `packages/dsh-task-board/src/client/locales.ts` 中新增中英双语 `board.hostError.forbidden`，并在 `packages/dsh-i18n/src/client/ru/task-board.ts` 中同步补齐俄语翻译。
   - 更新 `tests/host-api.spec.ts` 单元测试。

4. **跨平台路径分割兼容**：
   - 在 `packages/dsh-plugin-manager/src/host/profile.ts` 中兼顾正反斜杠分割并做路径规范化，确保 POSIX 风格测试用例在 Windows 环境下稳定通过。

## 后果

- 点击技能中心头部的「‹ 返回会话」即可流畅关闭中栏面板并回到会话正文。
- 在 DSH 0.1.7 下，`dsh-usage` 能够无缝读取由 profile patch 配置的 `apiKeyEnv`，自动完成余额与套餐额度探测，无需手动在 `.credentials.yaml` 中添加记录。
- 任务看板遇到 403 护栏拦截时，给出明确的环境同源校验提示，避免用户误判为登录失效。
