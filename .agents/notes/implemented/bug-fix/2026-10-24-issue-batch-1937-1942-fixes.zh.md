# Agent Note: Issue 批次 1937-1942——消费显示货币、预设行移除、安装器重试与配对闸门

Status: implemented

本笔记拥有 2026-10-24 交付的四处修复（issue #1937、#1940、#1941、#1942）。其中配对闸门的改动同时更新其归属笔记 [共享配对信任闸门](../simplification/2026-08-26-shared-pair-access-fence.md)；rc.3 cohort 迁移由 [SDK cohort 0.2.1-rc.3](../architecture/2026-10-24-sdk-cohort-0.2.1-rc.3.md) 拥有。

## Problem

四个未关闭 issue 各自源于一个被写死成常量或副本的错误假设：

1. **#1940——liangshen 预设在 0.2.1-rc.3 上挂不起来。** 预设声明了 `@deepseek-ai/dsh-tool-subagent-control/list-agents` 行。rc.3 移除了该子路径导出（`exports` 只剩 `.`），`list_agents` 改由控制行的 `apply()` 注册，于是每个 liangshen 会话都报 `tool-subagent-list-agents ... never started`。
2. **#1941——创意工坊安装器无法完成安装。** 单次抓取写死 30 秒、没有重试，并把 Cloudflare 托管挑战报成裸的 `manifest fetch failed: 403`。已发布清单本身约 190 KiB、直连实测 68.5 秒，于是健康下载看起来像卡死。
3. **#1937——所有消费金额写死成人民币。** 客户端在三处直接拼 `¥`，而账本存的是人民币估算，按美元结算的运维读到的数字与账单对不上。
4. **#1942——信任闸门在服务未注入时抛异常。** 详见闸门笔记：属性回退在只注入 `webServer` 的插件上，让每个非回环请求抛出 `cannot get property "remoteWebUiPairing" without inject`。

## Decision

1. 从 `packages/dsh-liangshen/presets/liangshen/agent.cordis.yml` 删除 `tool-subagent-list-agents` 行，并留注释说明为何不能加回来：rc.3 只导出包根，`list_agents` 由控制行自己注册。
2. `packages/dsh-market/src/core/installer.ts` 统一走 `fetchAsset()` 策略。单次超时默认 120 秒（`FETCH_TIMEOUT_MS`），超时、传输失败、408/429/5xx 走 `DEFAULT_INSTALL_RETRIES`（2 次）指数退避；Cloudflare 挑战（`cf-mitigated: challenge`，或 `server: cloudflare` 源返回 403/503）立即终止并以新的 `blocked` 错误码给出处置建议；其余 4xx 仍不重试。超时与重试次数都是该行的运维设置项（`installTimeoutSec` 30-600 默认 120、`installRetries` 0-4 默认 2），按请求解析，保存设置后下一次安装即生效。浏览器半区把 blocked 类渲染成自己的本地化句子，而不是原始 403。
3. `packages/dsh-usage/src/core/spend.ts` 拥有显示决策：`resolveSpendDisplay()` 归一化该行的 `spendCurrency`（`CNY`/`USD`，默认 `CNY`）与 `cnyPerUsd`（默认 7.2），`formatSpend()` 把一条已存的人民币成本渲染成该货币，非法输入给 0 而不是 `NaN`。宿主把解析后的显示写到概述文档的 `display` 字段，侧栏脚卡、用量页与 Token 银行都读它。账本继续只存人民币：切换显示从不迁移历史，也不抓取实时汇率，因此不存在会让卡片变空的抓取。
4. `shared/host/pair-access.ts` 在服务读不到时按「未配对」作答（见闸门笔记）；三份生成副本与 pet 卫星仓携带同一道保护。

## Alternatives considered

- **#1940**：保留该行并把 SDK 依赖放宽到仍导出 `list-agents` 的版本。否决：该子路径在目标 cohort 中已被设计性移除，钉住旧 cohort 等于撤销运维的升级。
- **#1941**：只提高超时。否决：慢源与瞬时 503 需要不同的处置，而 issue 真正抱怨的是两者都终结于一个不透明的状态码。改走浏览器半区下载再经回环交回宿主被否决为「新的宿主/浏览器协议」，超出本次修复范围；Range 断点续传未做，因为安装器本来就流式写入临时目录，一次重试足以清除现实中的失败。
- **#1937**：宿主抓取实时汇率。否决：该插件的宿主路由有回环门禁、浏览器半区无网络，抓取会引入 issue 明确要求避免的失败模式；由运维设定的汇率可确定、可测试。
- **#1942**：让每个消费方在 `inject` 里声明 `remoteWebUiPairing`。否决：那会让每个插件硬依赖 remote-web-ui，而闸门存在的意义正是避免这种依赖。

## Consequences

liangshen 预设在 rc.3 上重新可挂载，注释防止该行被加回。慢速或抖动链路上的安装每个请求有三次尝试才失败，拦截市场源的代理会得到一句用户能照做的说明。消费可以按美元阅读，且不触碰任何已存记录。闸门不再把缺失的可选服务变成 HTTP 400。
