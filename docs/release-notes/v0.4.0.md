118 commits: 18 new features, 37 bug fixes and 63 other changes. This is 0.4.0 because the family changed shape.

> **Important change**: the version moves from 0.3.x to 0.4.x because the family's membership changed, but there is **no breaking change that needs a manual migration**. The skin collection, the pet plugin and the community plugin index moved into three independent repositories that version on their own (all three released `0.3.25` here, which fixes the defect that kept the `0.3.x` family packages from activating on a 0.1.7-rc.1 host: they still injected the retired `settingsScope` service), and this repository now consumes them as npm packages. The aggregate keeps its row ids and its old subpath exports (`./pet`, `./skin-center`, `./community-plugins`) as tombstones, so an existing profile still resolves them instead of throwing `ERR_PACKAGE_PATH_NOT_EXPORTED`. `dsh-doctor` and `dsh-tool-describe-image` left the family by owner direction; each keeps a tombstone subpath export, so an old profile degrades to an inert plugin instead of failing to boot. The market no longer reads skin or pet content, or the community index, from a working tree: it reads the commits pinned in `market-inputs.lock.json` and verifies the assets deployed to the site. The pet, skin-center and community-index changes are recorded in those repositories' own release notes and are not repeated here.
