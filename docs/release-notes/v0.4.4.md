本次发布把家族适配的官方 SDK cohort 推进到 `0.2.0-rc.1`，让工坊商店复用官方插件面板，重做任务看板的排期时区、运行目标与治理，并带上四个卫星仓的 `0.4.4` 内容。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。任务看板的排期规则新增可选的 IANA 时区字段，旧规则缺少该字段时按宿主时区执行；任务的 `/goal` 开关只在关闭时落盘，字段缺省即开启。
> **宿主下限提升到 `>=0.2.0-rc.1`**：家族全部包与插件脚手架声明 `dsh.engines.dsh >=0.2.0-rc.1` 与同名 host peer，插件管理器在安装与更新时读取该下限。仍运行 `0.1.7-rc.2`（npm `latest`）的宿主低于该下限，请在插件管理器里更新家族包之前先把 DSH 本体升级到 `0.2.0-rc.1`（npm `next` 频道）。
> 四个卫星仓（皮肤中心、宠物、社区插件索引、预设中心）已先发布 `0.4.4`，本仓随后打 tag，聚合包按 semver 消费它们。

- [dsh-market] 工坊商店复用官方插件面板，不再自带一套商店界面

This release advances the family's adapted SDK cohort to `0.2.0-rc.1`, makes the Workshop store reuse the official plugin surfaces, reworks the task board's schedule zones, run targets and governance, and ships the `0.4.4` content of the four satellite repositories.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. A task-board schedule rule gains an optional IANA time zone and falls back to the host zone when the field is absent; a task's `/goal` opt-in is stored only when it is off, so an absent field means on.
> **The host floor moves to `>=0.2.0-rc.1`**: every family package and the plugin scaffold declare `dsh.engines.dsh >=0.2.0-rc.1` and the matching host peer, and the plugin manager reads that floor at install and update time. A host still on `0.1.7-rc.2` (npm `latest`) sits below it, so upgrade DSH itself to `0.2.0-rc.1` (the npm `next` channel) before updating the family through the plugin manager.
> The four satellite repositories (skin center, pet, community plugin index, preset center) have already published `0.4.4`; this repository tags afterwards and the aggregate consumes them by semver range.

### New Features

- [task-board] Each schedule rule carries its own IANA time zone and follows the host zone when none is set
- [task-board] A task can name its run target (an agent preset), and the create dialog is split into regions
- [task-board] A task run starts with dsh's built-in `/goal` and keeps working until the goal completes
- [task-board] An operator can settle a running card the board cannot observe; it returns to todo and can be run again
- [dsh-market] The Workshop store reuses the official plugin surfaces instead of shipping its own store UI

### Bug Fixes

- [web] Resolve the open issue batch 1743, 1744, 1745, 1746, 1748 and 1751
- [web] Resolve the open issue batch 1724, 1730, 1732, 1740 and 1742
- [plugin-manager] Installing into and removing from an application-owned profile go through the official plugin manager
- [task-board] Team runs are governed by the Lead and no longer stall silently in pending
- [task-board] Every teammate keeps a unique name inside one run
- [task-board] The preset feed is restored and client render and lineage-gate costs are cut
- [client] Fix the skill-explorer layout injection, the usage page's 0.1.7 settings and the task board's fence error
- [scripts] `link-profile` refuses to link a satellite checkout that cannot be loaded

### Other Changes

- [sdk] The official cohort moves to `0.2.0-rc.1`: the floor, the host peer, the README badges and the CI/release mount pin move together
- [skins] The satellite gitlinks and market artifacts follow the skin center's settings-row fix, the orca-link top-inset re-measure and the new skins
- [market] The market lists the new porco-rosso, last-exile and white-snake skins
- [shared] Dead shared artifacts (the `mobileBundle` and the sync copies nobody read) are removed and their references realigned
- [test] The two new BDD cases get role-led titles
