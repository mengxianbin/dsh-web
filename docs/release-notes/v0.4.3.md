本次发布把家族面板整体搬到宿主的原生布局席位，把自更新拆成独立的插件行，并把皮肤、宠物、社区插件索引与预设中心四个卫星仓的 `0.4.3` 内容一起带上。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式；设置页变化的是渲染席位，不涉及存储。宿主下限保持 `>=0.1.7-rc.2`，请先升级 DSH 本体再安装或升级本版本。
> 四个卫星仓（皮肤中心、宠物、社区插件索引、预设中心）已先发布 `0.4.3`，本仓随后打 tag，聚合包按 semver 消费它们。
> **自更新入口独立成包**：原先挂在远程访问插件里的自更新界面移到了 `@linxin666/dsh-update`，并作为独立 bundle 行 `web-ui-update` 进入聚合包。聚合安装会在升级时自动带上这一行；只单独安装 `@linxin666/dsh-remote-web-ui` 的 profile 需要另外安装该包，才能继续看到自更新入口。

### 新功能

- [dsh-update] 自更新拆成独立的插件行：关掉远程访问不再连带关掉自更新入口，探测 npm 上的新版本并在原地跑所属 profile 的更新
- [shared] 所有家族面板统一渲染到宿主的原生布局席位，技能中心与任务看板共用同一套席位契约
- [panels] 原生面板行的图标带上 `data-dsh-panel-entry` 身份锚点：皮肤（L2 契约）据此把样式落到自己的侧栏行，宿主侧栏不提供逐条目钩子
- [ssh] 终端会话可以超出打开它的视图继续存活
- [liangshen] V4.1 Flash 的评测口径与默认值按实测收敛

### 修复

- [plugin-manager] 应用自带的 profile 走官方插件管理器更新
- [settings] 家族设置卡片绑定到宿主实际服务的那条 profile 条目；使用量与远程访问的设置页恢复可写
- [remote-web-ui] 运行中的隧道按公网 URL 监督；LAN 访问绑定宿主启动的 profile；脚行席位不再挤坏设置行
- [shared] 上一次挂载尚未释放时被拒绝的家族挂载不再丢失，持有者退出后自动重放
- [dsh-web-all] 分组行与行操作下移动端抽屉保持展开；家族装饰下 macOS 窗口仍可拖动
- [task-board] 桌面外壳的 browser-auth cookie 在围栏处被接受
- [release] 根别名包的版本跟着发布 tag 一起走

### 其他改动

- [market] 市场产物跟随卫星仓 gitlink 更新到皮肤中心的选择器修复与重新锚定的皮肤行
- [skins] 皮肤行重新锚定到原生面板列表（`future-window`、`orca-link`、`wallpaper-exclusive`、`whale-fantasy`）
- [scripts] `link-profile` 的范围判断改用真正的 semver 比较
- [docs] CONTRIBUTING 要求提交卫星仓 submodule 变更；补记家族原生席位的归属笔记
- [test] 桌面页规格不再杀掉自己的 worker

This release moves every family panel onto the host's native layout seats, splits self-update into its own plugin row, and ships the `0.4.3` content of the four satellite repositories (skin center, pet, community plugin index, preset center).

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed; what changes on the settings pages are render seats, not stored data. The host floor stays at `>=0.1.7-rc.2`, so upgrade DSH itself before installing or updating this version.
> The four satellite repositories have already published `0.4.3`; this repository tags afterwards and the aggregate consumes them by semver range.
> **The self-update surface is now its own package**: it moved out of the remote-access plugin into `@linxin666/dsh-update` and enters the aggregate as its own bundle row `web-ui-update`. Aggregate installs pick the row up on upgrade; a profile that installs `@linxin666/dsh-remote-web-ui` alone needs this package too to keep the update trigger.

### New Features

- [dsh-update] Self-update becomes its own plugin row: turning remote access off no longer takes the update trigger away; it probes npm for newer releases and runs the owning profile's update in place
- [shared] Every family panel renders through the host's native layout seats, with the skill center and the task board sharing one seat contract
- [panels] Native panel-row glyphs carry a `data-dsh-panel-entry` identity anchor so a skin (the L2 contract) can target its own sidebar row; the host sidebar stamps no per-entry hook of its own
- [ssh] A terminal session can outlive the view that opened it
- [liangshen] The V4.1 Flash evaluation and defaults settle on what the measurements show

### Bug Fixes

- [plugin-manager] An application-owned profile is updated through the official plugin manager
- [settings] Family settings cards bind to the profile entry the host actually serves, and the usage and remote-access settings pages are writable again
- [remote-web-ui] A running tunnel is supervised by its public URL, LAN access binds to the profile the host booted, and the foot-row seat no longer breaks the settings row
- [shared] A family mount refused while its previous holder still lived is no longer lost; it replays once the holder exits
- [dsh-web-all] The mobile drawer stays open for group rows and row actions, and the macOS window stays draggable under family decorations
- [task-board] The desktop shell's browser-auth cookie is accepted at the fence
- [release] The root alias bundle carries the release tag version

### Other Changes

- [market] The market artifacts follow the satellite gitlinks to the skin-center picker fix and the re-anchored skin rows
- [skins] Skin rows are re-anchored on the native panel list (`future-window`, `orca-link`, `wallpaper-exclusive`, `whale-fantasy`)
- [scripts] `link-profile` compares the relink range as real semver
- [docs] CONTRIBUTING requires committing satellite submodule changes, and the native-seat ownership note is recorded
- [test] The desktop page spec no longer kills its own worker
