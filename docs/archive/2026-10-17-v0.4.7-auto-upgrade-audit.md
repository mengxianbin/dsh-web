## 1. Verdict

**BLOCK.**

One persisted loader identifier changed without any mapping, and one retired family package lost its only user-facing notice path. Neither is catastrophic at runtime (the loader degrades to a warning, proven in section 5), but section 0.3 makes an unmapped persisted identifier a stop condition, so the version bump must not proceed until B1 and B2 are resolved or explicitly downgraded with release-notes recovery steps.

## 3. Identifier inventory summary

1. Cordis row id `web-ui-model-capabilities` — removed, **no mapping** (B1).
2. npm package `@linxin666/dsh-client-ui-model-capabilities` — removed; only a load-time subpath tombstone survives (`@linxin666/dsh-web-all/model-capabilities` → `lib/shells/shell.js`), which keeps old imports from throwing but gives the user no replacement and no notice (B2).

6. Declared `dsh` floor `>=0.2.0-rc.2` → `>=0.2.1-rc.2` — a contract change that the update path turns into a 412 refusal on hosts below the floor (B4).

Explicitly frozen (verified unchanged by an automated literal-set diff over `packages/*/src` + `shared/`: 924 → 921 identifier literals, 46 removed / 43 added, all removals attributable to the retired package and to i18n keys): all API path prefixes, all request headers, all settings namespace constants, all settings section ids, all telemetry/localStorage keys, and `dsh.bundle` / `dsh.client` of every retained package. Reading: an upgraded 0.4.6 profile that had disabled (or configured) that row keeps booting, but every start prints the warning, and nothing in the release removes the dead override. Impact is cosmetic-plus-noise, not a boot failure — which is why B1 is a mapping/notice blocker rather than a data-loss blocker.

## 8. Classification of changes

- Backward compatible, no migration: aggregate rename absent (name frozen); `dsh.bundle`/`dsh.client` frozen; settings section ids, namespaces, API paths, headers, storage keys frozen; `exports` additions; `./invariant` removal (repo-enforced, no consumer); liangshen reading the legacy `presentation: 'both'`; dropped guard settings (unread, no error).
- Compatible, deterministic migration: legacy aggregate rename (`routes.ts:341-365` + `gateway.ts:804-965`, rollback and preflight present); row-level enable/disable edits (`rows.ts:22-25,235-283`).
- Incompatible / blocking: `web-ui-model-capabilities` row removal with no mapping or cleanup (B1); retired package without a replacement or notice (B2); missing Doctor entry point and a `dsh web` entry point that silently performs no upgrade, both undocumented (B3); declared DSH floor above the registry `latest` so the automatic path refuses on stable hosts until notes say otherwise (B4).
